# ML Weekly Task - Regression and Classification

A small web dashboard that shows basic machine learning techniques. All models are written from scratch in plain JavaScript (no ML libraries). Chart.js is used only for drawing the regression graph.

## Techniques
**Regression** (hours studied vs marks)
- Linear Regression
- Polynomial Regression
- Ridge Regression (L2)
- Lasso Regression (L1)

**Classification** (hours studied + attendance -> pass/fail)
- Logistic Regression
- KNN

## How to run
Download `index.html` and open it in any browser. No installation needed.

## What it shows
- Train/test split and R2 / MSE for regression
- Overfitting with high-degree polynomials, and how Ridge/Lasso reduce it
- Decision regions for Logistic Regression and KNN, and the effect of k
- Train and test accuracy for both classifiers
