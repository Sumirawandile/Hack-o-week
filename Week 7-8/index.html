Notes:

  • Linear fits a straight line y = b + w*x.
  • Polynomial adds x^2, x^3 ... so the line can curve. A very high degree (like 10) fits the training points too closely and does badly on test data (overfitting).
  • Ridge is polynomial regression with an L2 penalty (lambda) that shrinks the weights, which reduces overfitting.
  • Lasso uses an L1 penalty, which can push some weights to exactly 0.
